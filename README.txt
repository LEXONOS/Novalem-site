STUDIO NOVALEM — SITE VITRINE
=============================

Ce dossier contient le site, prêt à mettre en ligne.

CONTENU
- index.html : le site complet (tout est dedans : design, animations, sons, portrait particules).

METTRE EN LIGNE
- OVH / FileZilla : glissez index.html à la racine de votre hébergement (www/).
- Vercel / Netlify : glissez le dossier, c'est en ligne en une minute.
- Le site a besoin d'internet pour charger 3 librairies (GSAP, ScrollTrigger, Lenis)
  et les polices Google. En local, ouvrez simplement index.html dans Chrome.

BON A SAVOIR
- Le bouton "son" en bas à droite active/coupe les sons d'interface.
- Le portrait en particules du hero réagit au curseur. Pour changer l'image source
  plus tard, on remplace le bloc concerné (dites-le moi, je le fais).
- L'apercu live d'IFC (section Réalisations) s'affiche une fois le site déployé.

A VENIR (couche finale)
- Sons personnalisés, petite IA "Nova", formulaire de contact branché sur le mail,
  optimisation image, fichiers logo (SVG / favicon / PNG).
